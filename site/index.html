Votre parcours

Installation en 6 étapes

Cochez les étapes terminées pour suivre votre progression.

Progression0 / 6
01

Créer votre machine Codespaces

Connectez-vous à GitHub, ouvrez notre dépôt et choisissez Code → Codespaces → Create codespace on main. Attendez l'ouverture de VS Code dans le navigateur.

Ouvrir le dépôt GitHubWin10 ↗
Chaque étudiant utilise son propre compte et crée son propre Codespace.
02

Ouvrir le terminal et contrôler la machine

Dans Codespaces : Terminal → New Terminal. Vérifiez Docker, KVM, les CPU et l'espace de stockage.

cd /workspaces/githubwin10
docker version
docker compose version
bash scripts/check-host.sh
Avec 32 Go de stockage GitHub au total, Windows peut manquer d'espace pendant l'installation. Le disque virtuel de 32 Go ne représente pas l'espace réellement libre.
03

Créer un mot de passe Windows

Créez votre fichier privé, puis remplacez la valeur de WINDOWS_PASSWORD par votre mot de passe personnel. Dans nano : Ctrl + O, Entrée, Ctrl + X.

cp .env.example .env
nano .env
Ne partagez jamais votre mot de passe. Le fichier .env est ignoré par Git.
04

Démarrer Portainer

Portainer est une interface graphique pour visualiser et gérer vos conteneurs Docker.

docker compose up -d portainer
Dans l'onglet Ports, ouvrez le port 9000 et créez votre compte administrateur Portainer.
05

Démarrer Windows 10

Le script détecte KVM. Sans KVM, il s'arrête pour éviter une installation extrêmement lente sans votre autorisation.

bash scripts/start-windows.sh
Si « KVM indisponible » apparaît, demandez conseil avant de tenter une émulation logicielle.
06

Ouvrir les interfaces

Dans Codespaces, ouvrez l'onglet Ports et cliquez sur les liens. Vérifiez que la visibilité reste Private.

PORT 9000PortainerGestion des conteneurs
PORT 8006Bureau WindowsInstallation et bureau web
Le premier démarrage peut être long. Ne fermez pas le Codespace pendant l'installation.

Commandes utiles

Arrêter les conteneurs et résoudre les erreurs courantes.

Gérer votre machine

Windows et Portainer peuvent être arrêtés séparément sans supprimer le disque.

docker compose stop windows
docker compose start windows
docker compose --profile windows logs --tail=100 windows
df -h && docker system df -v

Questions fréquentes

Docker ne répond pas

Ouvrez la palette Ctrl + Shift + P et recherchez « Codespaces: Rebuild Container ». Si le daemon reste inaccessible, demandez de l'aide.

KVM n'est pas disponible

Le fonctionnement sans KVM est possible, mais l'émulation QEMU est très lente et consomme vos heures de calcul.

Il n'y a plus de place sur le disque

Le Codespace de 32 Go comprend Linux, Docker, l'ISO Windows et les données. Vérifiez df -h et docker system df -v. Ne supprimez aucun volume sans sauvegarde.

Je ne vois pas les ports 8006 ou 9000

Vérifiez docker ps, puis ajoutez le port dans l'onglet Ports avec « Forward a Port ». Gardez les ports privés.

Puis-je partager mon Codespace ?

Chaque étudiant doit créer le sien depuis le dépôt. Les quotas GitHub et la licence Windows s'appliquent individuellement.
